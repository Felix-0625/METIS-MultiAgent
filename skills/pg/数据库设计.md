# 数据库设计

- **版本**: 1.0.0
- **描述**: 负责数据库 Schema 设计、索引优化、查询优化、数据迁移
- **标签**: pg, database, sql, postgresql
- **分配给**: pg

---

## 数据库设计 Skill

### 支持数据库
- 关系型：PostgreSQL / MySQL / SQLite
- 非关系型：MongoDB / Redis
- 搜索引擎：Elasticsearch

### 设计规范
1. 范式化设计（至少满足 3NF）
2. 主键使用 UUID 或自增 ID
3. 必要字段：created_at / updated_at / is_deleted
4. 索引策略：高频查询字段建索引，避免过度索引
5. 外键约束 + 级联规则明确

### 输出
- ER 图（Mermaid 格式）
- DDL 建表语句
- 索引设计说明
- 数据迁移脚本（Alembic）
