# 文档生成

- **版本**: 1.0.0
- **描述**: 根据代码、需求或会议记录，自动生成技术文档、API 文档、用户手册
- **标签**: common, documentation, writing
- **分配给**: pm, pg, supervisor, hr, ccb

---

## 文档生成 Skill

### 文档类型
- 技术设计文档（TDD）
- API 文档（OpenAPI/Swagger）
- 用户手册
- 部署文档
- 会议纪要

### 输出格式
- Markdown（默认）
- HTML
- PDF（需要 pandoc）

### 模板
遵循公司文档规范，包含：
- 文档标题、版本、作者、日期
- 目录
- 正文
- 附录
